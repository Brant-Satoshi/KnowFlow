## 如何重复检查

在项目根目录运行 [批量检查脚本](/Users/brant/Projects/ai/ai-projects/knowflow/scripts/check-answer-judge.ts)。原来的单题脚本和用户编写的评分函数没有在本次保存时修改。

复核已保存的输出，检查当前解析函数能否处理这些 JSON；不调用模型：

```sh
node --import tsx scripts/check-answer-judge.ts
```

重新调用模型，顺序评分全部五条固定输入：

```sh
node --import tsx scripts/check-answer-judge.ts --live
```

`--live` 使用项目的 `.env.local`，优先使用 `EVAL_JUDGE_MODEL`，未设置时使用项目默认模型。每条会发起一次模型请求，不运行检索或写数据库。程序保留评分失败为 `unscored`，不会把它从总数中移除。

脚本将完整 JSON 报告打印到标准输出，摘要打印到标准错误。需要保存一次新运行时，可以重定向标准输出到一个新的文件，例如：

```sh
node --import tsx scripts/check-answer-judge.ts --live > /tmp/answer-judge-rerun.json
```

新报告记录输入、人工预期、实际结果、原始回复、请求的模型标识和提示词哈希。全部符合预期时退出码为 0，有分歧或未评分时为 1。
